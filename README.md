# youtube-publisher-agent

Agente de publicação no YouTube para a Agent Platform.

## Objetivo

Este repositório contém o agente `youtube-publisher-agent`, responsável por interagir com a YouTube Data API v3 usando o motor declarativo da plataforma.

Capacidades planejadas:

- listar canais do usuário autenticado;
- listar playlists;
- publicar vídeo local no YouTube;
- atualizar metadados de vídeo existente.
